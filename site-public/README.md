# Tastebridge (site public)

Fichiers générés du site https://rayancv94.github.io/tastebridge/ : ne pas les modifier ici.
Le code source est dans un dépôt privé ; il publie ce dossier avec `python publier.py`.

Seule chose qui vit ici : `maj.py`, lancé chaque jour par `.github/workflows/tendances.yml`,
met à jour les tendances de la semaine (Wikipédia, SteamSpy) dans `tastebridge/tendances.json`.
